## Changelog

No call the brain makes follows a redirect (SMD-2908). The egress gate judges a provider endpoint's base, and Bun's fetch followed a 307 with the request's body to wherever it pointed, so an endpoint declared local could send captured text to another host. A 3xx is now refused where it lands, naming where it pointed: set the base there, and the gate judges it. Preflight's `--deep` probes fail on one, and the start's provider row warns.

## Record

No call follows a redirect: a provider's 3xx is refused where it lands, so a base the egress gate judged cannot bounce brain text to another host (SMD-2908)

**What changed.**
- **Every dialler of brain text** passes `redirect: "manual"` and refuses a 3xx through `refuseRedirect` (`server-portable/embed.ts`): a `ProviderError` of kind `http` with the status, naming the `Location` with its userinfo masked. The diallers:
  - `providerCall`'s exchange: embeddings and chat, the digest's synthesis included;
  - the consolidation judge (`judgeRequest`);
  - extraction (`entities.ts`);
  - decide mode's writer (`consolidate-decide.ts`);
  - the digest's Telegram post (`db/weekly-digest.ts`), whose bot token is masked in the target it names, as written and percent-encoded.
- **The probes follow none either, and read a 3xx as refused:**
  - a worker's chat probe (`probeChat`) says `refused`, not `up`, which its fall-through for an unnamed status said;
  - the model list (`modelListed`) says `unknown`;
  - the decide tier's probe says `refused`, not an outage waited out. Its client (`jev.ts`) already followed none.
- **A worker stops its pass on one.** `classifyError` reads a 3xx as fatal, as it reads a 4xx: the base redirects every call. `providerDown` reads it as no outage.
- **Preflight:**
  - the `--deep` probes fail by name, with the knob to set;
  - the start's reachability row warns, naming where `/models` points. It doesn't fail, since `/models` may redirect where the calls do not, and `--deep` tells.

**Why.** Found by SMD-1849 PR 2d's adversarial review and measured again here on Bun 1.4.3. An endpoint at 127.0.0.1, declared local, answered 307 to another origin, and Bun re-sent the POST there with its body, dropping only `Authorization`. The gate's promise, that an endpoint not declared local gets the text only under the policy, did not hold past the first hop. The provider span named the declared host, so the trace said the call stayed local.

**Upgrading.** A base that redirects, such as `http://` to a provider that answers on `https://`, worked before and now fails every call, naming where it points. Set the base to that address. Stable's and the canary's endpoint, Ollama on the host, answers its calls with no redirect (checked 2026-11-07).

**Held.**
- `test-local-provider.ts` [13] points each dialler at a stub that redirects to a second stub:
  - providerCall's embedding and chat calls, under 301, 302, 303, 307 and 308;
  - the judge, extraction, the probes, the decide tier and the Telegram post.
- **Each fails as a redirect, and the second stub receives nothing.**
- **A guard over the files:** every bare `fetch` in `server-portable/` (its `core/` and `rest/` too) and `db/` passes a `redirect` option. The two that dial no provider are named, each counted: the benchmark's calls to the brain's own `/mcp`, and the OAuth edge's pass-through.
- **Seven mutants, each killed by the suite named:**
  - extraction's option dropped: the far stub received the chat request's body, the leak reproduced;
  - the exchange's refusal dropped;
  - the probe's refused branch dropped;
  - `classifyError`'s redirect rule dropped;
  - the Telegram target left unmasked;
  - preflight's and the digest's options dropped, each named by the guard by file and line.
- **The other suites:**
  - `test-thoughts.ts` holds decide mode's writer;
  - `test-preflight.ts` [9] holds the reachability warning and the `--deep` failures;
  - `test-worker-bootstrap.ts` holds `classifyError`.
