**What changed.**
- **Check 54** in `scripts/check-consistency.ts` reads every file git lists (tracked, and untracked but not ignored), outside the archive: `changes/`, `CHANGELOG.md`, `db/migrations/` and `FORK.md`, the fork era's record.
  - It reads each line for "Open Brain" in any case, and for "fork", "forks" or "forked" as a word. Each pattern is a plain word boundary, so none can backtrack far (JSC gives up silently at its limit).
  - A line it flags fails with its file and line, and a message that says what to do.
  - It doesn't read the checker itself, which names the words in order to look for them.
- **Shapes that make no claim** are cut from a line first, each held by a probe that must pass:
  - a URL, and a markdown link to upstream's repository with its text (the origin's links);
  - the origin sentence, "grew out of Open Brain" and "began as a fork of";
  - upstream's maintainer-team badge (attribution);
  - identifiers: `FORK.md` as a file, the `ob1-fork` marker, CI's name before SMD-3765 (`fork-checks`, "Fork Checks"), the `[fork]` commit type commitlint keeps for old commits, and `fork` quoted as a token;
  - other senses: a process `fork()` and GitHub's "fork network".

  Its probes must flag "this fork" in a doc, "the fork's" in a comment, "Search Open Brain" in a tool title, a prerequisite and a credential tracker. And the archive's four parts must be left unread, and live files read.
