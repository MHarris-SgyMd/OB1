## Changelog

The session-capture hook blanks a secret it finds in a summary to `[redacted:<reason>]` and sends the rest, where a hit refused the whole episode — one real key in a long session cost the session its memory; the blanked text is scanned again and refused if anything remains, `OB1_CAPTURE_ON_SECRET=refuse` restores the refusal for every hit, and a rule that names a value blanks the value alone (SMD-2127).
