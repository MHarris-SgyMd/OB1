## Changelog

A thought's state on three axes, read from the records the brain already keeps: `thought_validity` says whether it still holds, whether someone decided on it, and whether what was derived from it has caught up, naming the records it read and any it could not (SMD-3887, migration 148). It labels only; no default read changes.

## Record

A thought's validity, review and freshness are read from the records that exist — no record contesting it reads unchallenged, never supported (SMD-3887)

**What changed.** Migration 148 adds `thought_validity(uuid[])`, the read `docs/claim-validity.md` decides (rows 1 to 7 and 9 to 11, accepted by the maintainer on 2026-11-19). It is STABLE and SECURITY INVOKER, and writes nothing.
- **The call.** Up to 100 distinct ids, answered in the order given; a repeat is answered once, NULL is `NO_IDS`, and a call over the cap is refused whole (`TOO_MANY`). An id that is no thought answers found false, and forgotten with its time when 139's ledger holds it.
- **Validity:** superseded (068's projection, naming the superseder, the key that wrote its pointer and the proposal that did, if one did); contested (a pending proposal on it as the side that falls, both texts as judged; or a corrected verification whose checkpoint reads current or unmatched); unresolved (the same proposal once a side's text moved since judged, or a stale one; or a corrected verification at an earlier text); supported (an active citation whose source stands and, one level deep, is neither superseded nor challenged); else unchallenged. Unknown when a table the caller's role cannot read could have set a state above the one found, which is named in `found`.
- **Review:** pending, decided (the reviewer and kind, and whether the pass settled it), checked (the verification's status), unchecked, none.
- **Freshness:** over the lineage rows naming it whose artifact still stands, the worst of stale (an input's key moved, read as `rebuild_derived` reads it), requested (a rebuild asked, or a proposal is stale), legacy and current; none with no such row. A row whose artifact is gone is listed as orphaned and not read. A stale or requested kind no pool re-runs says so.
- **Versions and numbers.** Each thought carries its key now (the stored one, else the text's) and its newest audit seq. A judge's number carries `calibrated: false`. Without the audit log, a corrected checkpoint that is not the text now reads unknown.
- `unread` names each record kind the role could not read.

The operation over REST and MCP is SMD-3887 PR 2b.

**Why.** Seven records say in their own words whether a thought holds, and nothing read them together. SMD-3900's eligible read and the revision tickets beside it (SMD-3895 to SMD-3903) wait on one read and one vocabulary. On stable on 2026-11-19, no lineage row was marked stale while 2,266 standing derived artifacts had been made on a text that has since moved, so freshness is the fingerprint read; and nothing calls `rebuild_derived` on an edit, so a pending proposal on an edited text stays pending, and unresolved is read from fingerprints too.

**Held.** test-schema [133]: the call's shape and refusals; no record reads unchallenged, never supported; each transition the record names, read back through the function (a pointer set and cleared; a proposal pending, its text moved, stale under a forced rebuild, accepted, rejected; a citation's source standing, superseded and deleted; a deliverable unverified, corrected at the current, an earlier and an unmatched checkpoint, and verified again; a lineage row current, stale, requested and current again); one thought unchallenged, pending and stale at once; an unread table unknown on the axes resting on it; forgotten; the function's shape; a re-apply a no-op. test-upgrade [20ck]: refused by name without 068's projection, then applied onto a populated brain, whose thoughts read superseded, contested and unchallenged. Twenty-one mutants of the migration, each killed by [133].
