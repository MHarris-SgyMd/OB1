## Changelog

The vendored servers' suites and shared install move from `extensions/` to `integrations/`, where most of those servers live, and what the extension servers left behind retires: the `_shared/sse.ts` keepalive copy, the core's `mcpReply` and `vendoredStalledLine` that only it used, `extensions/_shared/auth.ts`, and test-auth's MCP server checks, since no vendored MCP server is left on the shared install (the Vercel recipe's route runs on its own) (SMD-3747). That install is then `hono` and `zod` alone, the v1 MCP pair dropped; the extension template becomes a plugin template, an extension's guide beside its plugin's code; `primitives/deploy-remote-mcp` becomes Run a Vendored Server, and `primitives/remote-mcp` the guide to connecting any client to the brain's own connector.
**Upgrading:** run `bun install` in `integrations/` in place of `extensions/` (`(cd integrations && bun install)`), and delete a leftover `extensions/node_modules`; a recipe resolves that install through `recipes/node_modules`, which now links to `../integrations/node_modules`. Checking out a commit from before this one deletes `integrations/node_modules`, an ignored directory to git, and puts back the links to `extensions/node_modules`: run `bun install` in `extensions/` there. `bun install` leaves the dropped MCP pair's packages in an existing `integrations/node_modules`: delete it and install again for the install CI runs.

- **What the extension servers left goes.**

- **What replaces the checks that still matter.** The "each form a key may travel in" check asked an MCP server's tools/list; it now asks the HTTP API: under each of `x-access-key`, `x-brain-key`, a bearer and `?key=`, a read key passes the read probe and is told a write route writes. The same loop runs at each worker: a read key's dry run passes and its real run is refused, through every form. Each loop also sends a wrong key in each form and wants 401. A new guard fails any script under the three category directories that imports an MCP server package or builds a server transport (Streamable HTTP, SSE or stdio, in the spellings its own probe lists; the Vercel route, on its own install, named as the one exception), so a vendored MCP server fails before it lands: new operations on the brain are a plugin. The byte-copy check also fails a `_shared/sse.ts` under those directories, and `sync-auth`'s command is held, not only the directories it names.
- **Which side of the version contract.** Vendored code and its test tooling, outside the contract (MAINTAINING.md, "Versioning"): a minor, with the Upgrading line above. The core's removed `sse.ts` exports were no route or setting of a shipped image.
