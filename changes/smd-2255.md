## Changelog

`search_thoughts` takes an opt-in `prefer_current`: migration 059's `search_thoughts_current` ranks settled (a ticket completed or canceled, a note filed under one included) and superseded thoughts below current ones, by 058's `node_state`, at 0.25 of their fused score — priced first in `eval-supersession.ts`; off by default, so the default ranking is unchanged; the query log records it as arm `current`, and the server group reads `thought_sources` (SMD-2255).

## FORK

search_thoughts' prefer_current ranks finished and replaced work below live work, opt-in, priced before it was built (SMD-2255)

**What changed.** SMD-2074's second consumer of 058's `node_state` (its first
PR moved graph-centrality onto it). `db/migrations/059_search_prefers_current.sql`:
`search_demote_weight()` (IMMUTABLE 0.25, the one place the weight is written)
and `search_thoughts_current(...)` — the hybrid's seven parameters and eleven
columns, then `fused`, `demoted` (the status_type and/or `superseded` that
weighted a row) and, on every row, the window's size, lifecycle coverage,
demoted count, latest source watermark and exactness. Over the hybrid's top
min(100, 4N) — read `WITH ORDINALITY`, `node_state(NULL)` joined and inlined —
a thought whose ticket is settled (058's ticket-head rule, so a note under a
Done ticket counts) or that a newer thought supersedes weighs 0.25 of its fused
score, once; the window is re-sorted, ties in the hybrid's order, and cut to N.
Blocked and unknown-status thoughts are never demoted. LANGUAGE sql with a
string body, STABLE, `jit = off`, invoker; dropped before it is created (058's
trap); `query_log.arm` admits `current`. Stores: `hybridThoughts` takes
`preferCurrent` (the SQL store picks the function, PostgREST the RPC);
`ThoughtHybridMatch` gains `fused`, `demoted` and `window`. The tool:
`prefer_current` (default false; off calls the hybrid, so today's order is
exact by construction), a `↓ Ranked ×0.25 — completed` line on a demoted hit
(the weight read off the row), a header note on the window — and "raise limit"
when it held fewer current rows than asked — and an error that names 059 or the
grant rather than silently searching without the flag. ChatGPT's `search` never
demotes (`SEARCH_COMPAT_PREFER_CURRENT = false`). `db/tier.ts` replays arm
`current` through the function; the utilization readers name it. The server
group gains SELECT on `thought_sources` (node_state reads it).

**Why.** Ordinary search ranked a completed ticket, or a replaced decision,
exactly like live work — 41% of the dogfood brain's OB1 footprint is Done
(SMD-1994's census). 025 kept supersession labelled, not demoted, and named
`eval-supersession.ts` the instrument any demotion must pass; SMD-1720 showed a
resolving read changes what counts as relevant. So: opt-in, priced first.

**Held.** `eval-supersession.ts`'s second section (evals/README.md, "Settled
and superseded, ranked below on request"), pre-registered: CURRENT +0.052 and
LIVE +0.194 over the default, demote 0.200 against exclude 0.000 on PREVIOUS;
TOPICAL −0.127, NOTE −0.292, SETTLED −0.161, a settled key −0.750 / −0.500,
disclosed. Controls hold; SQL = oracle and the window exact on 288 of 288.
Three runs, each on the maintainer's call: 12 per class missed the bar
(+0.039); a replication at 48 cleared it but its controls failed on the index
walk's count-dependent candidates; rerun on the exact branch, the controls hold.
`test-schema.ts` 1847 — new [55]: the contract; with nothing to demote, the
hybrid's first N at the window, row for row and score for score (the hybrid at
N itself for a query with no identifier); who is demoted and by exactly 0.25,
once, ties in order; the literal cost; the window both ways; the coverage

**Measured after.** The dogfood brain (a read-only dump, 945 thoughts, 315
demotable), 59 logged searches: the top result changed in 20, each time a
settled or superseded one; the window exact on 59. Latency
(`db/bench-hybrid.ts`'s new arm): +10.7 ms over the hybrid's 1.1 at 10,000
thoughts, +129 ms at 100,000, +2.8 ms over 2.4 on the dogfood brain —
node_state computes the whole brain per call. **The pre-registered budget (at

on the maintainer's call, the cost stated on the tool and in 059.

Degrading to the hybrid when 059 or the grant is missing. A preflight check
