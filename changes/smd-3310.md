## Changelog

The old SvelteKit dashboard (`dashboards/open-brain-dashboard`) retires with its CI steps, and the `dashboards/` category goes with it, the upstream landing page and the template included. The operator GUI at `/dashboard` is the brain's one dashboard, and FORK.md says so; a community dashboard is now a plugin's pages. **Upgrading:** no compose service ever ran the old dashboard; a copy deployed by hand keeps working against the MCP server until removed, and a contribution's `metadata.json` can no longer say `"category": "dashboards"` (SMD-3310).
