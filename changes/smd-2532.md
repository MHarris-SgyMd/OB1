## Changelog

**Breaking:** the origin root is retired. Through the stack's proxy, `POST /?key=…`, `GET /`, `/worker-status` and `/jobs/<id>` at the root are its own 404 (body `404 page not found`), no longer the MCP server: the legacy route that kept clients configured before the proxy working, each answer deprecated since v1.6.0, is gone, and so is `tier-off`, its guard for paths under `/canary` and `/working`, which are the same 404. Move a client still on the root to `/mcp`, the same port with `/mcp` added (`deploy/README.md`, "Moving a client to /mcp"). A client of the server itself, with no proxy in front, is unchanged. The server no longer logs a key still on the root, and its CORS answers no longer expose `Deprecation` or `Link`, which only the legacy route sent (SMD-2532).

**Not taken.**
- Removing `oauth-fallback-off`, `api-off`, `hooks-off` and `grafana-off`, which no longer keep a path off the legacy route: each stays its path's owner, a bodiless 404 the overlays' priority-36 routers win over, and CI holds each to its own 404.

**Why.** SMD-2306 opened the window with v1.6.0 (tagged 2026-10-08) and decided it closes with v2.0.0, no sooner than two weeks after: 2026-10-22. Removing a URL a configured client uses is FORK.md's MAJOR. Both dogfood brains' clients had moved to `/mcp` (SMD-2686), and SMD-3101's removal of the tier routes makes the same release v2.0.0. The maintainer chose (2026-10-21) two PRs, `tier-off` removed with the route, and the marker's server logging and `not-legacy` removed in PR 2.
