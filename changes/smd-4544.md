## Changelog

The session hook (1.11.7) finds a work-claim token (`wc_` and 64 hex) glued to a letter or digit before it, such as `xwc_<hex>` or a URL-encoded `%3Dwc_<hex>`, which no rule took before: it went to the brain in the summary and to the model in the excerpt (SMD-4544). The brain's sensitivity table (`db/sensitivity.ts`) marks it restricted too. **Upgrading:** replace the script and its `lib/` together; no config changes.

## Record

The work-claim rule takes a token glued to a letter or digit (SMD-4544)

**What changed** (`recipes/session-capture-hook/lib/secrets.mjs` and `db/sensitivity.ts`, the same literal; 1.11.7).
- **The `work-claim token` rule** drops its lookbehind `(?<![A-Za-z0-9])`: the token is the run `wc_` and 64 hex, whatever precedes it. Its trailing guard stays, so a longer hex run is not one.
- **What it reverses:** SMD-3615 read `xwc_` and `9wc_` before 64 hex as a word's, a near miss. The suite's two near-miss probes for them become catches; the 63- and 65-digit near misses stay.
- **The 64-hex rule's own lookbehinds** are unchanged, so a digest beside an underscore or a letter reads as before.
- **1.11.7**, in `lib/hook.mjs` and `metadata.json`; the README's Testing list names the cases.

**Why.** SMD-3656's review pass 1 (secrets adversary) found a claim token with a letter or digit before it taken by no rule: the work-claim rule's lookbehind refused it, the 64-hex rule's lookbehind refuses a run after `_`, and the entropy rule skips hex. A token proves a claim to anyone holding the claim's key, so it went out whole. `wc_` and 64 hex after a word's letters is no digest's or identifier's spelling, and no text in this repository holds one.

**Held.**
- **The suite** passes under Bun: 1,096 assertions — two near-miss assertions gone, one new.
  - **Glued tokens:** after `x`, after `%3D`, after a digit, and in upper case, each is blanked in a prompt and in the outcome, the gate passes the blanked text, and the model's excerpt is withheld.
  - **Near misses:** 63 hex and 65 hex after `wc_` are still no claim token.
- **Two mutants each fail the suite:** the lookbehind restored, and a digit before the token still refused.
- **A differential against main** (the hook as at 73404178, unchanged since), through the episode path, over 4,536 texts in a prompt and in the outcome, a token with every kind of neighbour before and after it: no finding main makes under refuse is lost, nothing main does not send is sent, no episode main's gate passes under redact is refused, and no excerpt main withholds is sent. What the branch newly blanks is, every time, a token after a letter or digit.
- **The brain's copy:** the table equals the hook's; the near-miss samples `db/test-live.ts` holds standard keep their tiers.
- `tsc --checkJs --noUnusedLocals` and `scripts/check-consistency.ts` pass.

**Not taken.**
- **A token split by a line break or a space** (`wc_<32 hex>⏎<32 hex>`) is read as before: the run is the token.
