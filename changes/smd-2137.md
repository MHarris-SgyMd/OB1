## Changelog

`recipes/obsidian-vault-import` is gone: the Markdown adapter of the ingestion contract (`db/ingest-markdown.ts` — `bun db/ingest-records.ts --source markdown --markdown <vault> --allow <vault>`, then `bun db/reembed.ts`) is the fork's Obsidian import, so the root README row points at it, the connector registry and check 24's exception table lose their rows, and the recipe's heading split with LLM distillation, its filters, secret scan, sync log and source label go with it, the ones worth having filed on the two-way connector's ticket — each named (SMD-2137).

## FORK

The Obsidian vault import recipe retires — the Markdown adapter is the fork's import, one file one thought with the file kept byte for byte, and what the recipe had that the adapter has not is named, dropped or handed to the two-way connector, nothing ported (SMD-2137)

**What changed.** `recipes/obsidian-vault-import` — `import-obsidian.py` (947
lines), its README, `metadata.json`, `.env.example`, `requirements.txt` and

**Why.** SMD-2126 decided the class: an import becomes an adapter of the
contract, a maintenance script moves onto the shim, and a script whose
capability is in core retires. This one is in core to the letter — the ticket's
own comparison, feature by feature, found every capability of the recipe's
either in the adapter and pipeline (dedup by fingerprint and deterministic id
for the sync log; `--dry-run` for `--limit`, `--report` and `--verbose`;
`reembed.ts` for `--no-embed`; the title line for the content prefix; a
refusal by name where the recipe replaced undecodable bytes with U+FFFD) or
an enrichment past the seam (the
heading split with LLM distillation, which the registry's own dividing line
already called one) or a filter the connector should own (`--min-words`,
`--skip-folders` and the `templates`-folder exclusion, `--after`, a per-vault
label, a pre-`--allow` key-material scan, an mtime `created_at`). Nothing is
ported into the adapter here: the ticket's rule was to file, not port, and
SMD-1814 carries the list as a Work paragraph.
