## FORK

The session hook captures at checkpoints — a compaction is one, and the session's end supersedes it (SMD-2012)

**What changed.** `recipes/session-capture-hook/session-capture.mjs` prints
per-harness default events (`DEFAULT_EVENTS`): for Claude Code the pair
`SessionEnd` + `PreCompact`, one command each, both with `timeout: 10`; for
Codex `SessionEnd` alone, since Codex has no compaction hook — `--print-hook
codex --event PreCompact` is refused with the Stop alternative named. `--event`
is held to `HOOK_EVENTS` (SessionEnd, PreCompact, Stop): a misspelt event
(`precompact`) would have installed a hook that never fires, and nothing would
have said so; the refusal names the case. `checkpointOf(hook)` reads the event
— PreCompact with its `trigger` when it is `manual` or `auto`, Stop as a turn's
end, anything else as an end — and `renderSummary` writes it as a `Checkpoint:`
line before the closing `Session` line: `compacted at 2026-09-23 11:49 (auto),
continuing — the session's next checkpoint or its end supersedes this summary`,
or `turn ended at <time>, continuing`. The moment is the transcript's last
timestamp, never the clock, so the fingerprint does not move with time. The
payload carries `trigger`; the log line names the event when it is not
SessionEnd. The Stop interval stays Stop's alone: a compaction is rare and an
episode boundary, so it is never gated. The local half ran unchanged for the
event already; each capture supersedes the session's earlier one, so a session
stays one current thought that grows at every checkpoint.

**Why.** The first dogfood session (2026-09-23) ran two days across several
compactions and many tasks; installed as SessionEnd alone, the hook would have
left one thought at the end, titled after the first task, with forty-two
prompts flattened into twelve lines, and every session running beside it read
nothing until then. Claude Code's `PreCompact` fires before every compaction,
manual or automatic, with the same stdin shape plus `trigger`; it shares no
time budget (a command hook's 600 s default), cannot block the compaction, and
the transcript file may lag the conversation by a message or two when it fires
— the session's end has them all. It is pinned to 10 s all the same, because a
compaction waits on it.

**Held.** `test-session-capture.mjs` (314 assertions, in CI's
repo-consistency job): `checkpointOf` on each event and on a trigger that is
neither; the Checkpoint line's text, position and determinism, an undated one,
a Stop's; `prepare` on a PreCompact input, ungated by the interval, twice; as a
hook over the fake server, a PreCompact capture naming the compaction and the
session's end superseding it with a summary naming none, the transcript
unchanged; the log's `event=`; `hookJson`'s default pair against Codex's
single, PreCompact's timeout, one event alone; the CLI's refusals for Codex +
PreCompact, a misspelt event and an event the hook has no use for. Ten mutants
— no line, SessionEnd alone as the default, the two refusals dropped, the
timeout dropped, the trigger unvalidated, the checkpoint never set, Stop read
as compacted, the time from the clock, the log silent — each fail at least one.

**Not taken.** `SessionStart` with the `compact` matcher — it fires after the
compaction, when the transcript already carries the compaction summary;
PreCompact sees the episode whole. One thought per compaction — that is
segmentation (SMD-2013), which changes what `supersedes` means and needs its
design note first. Gating PreCompact by `--min-interval`. Adding the checkpoint
to `--dry-run`, which has no event.

**Follow-ups.** SMD-2013 (per-episode thoughts), SMD-2014 (opt-in model
summary). Dogfood: the PreCompact entry is in `~/.claude/settings.json` since
2026-09-23; re-copy the script to `~/.local/share/open-brain/` after this merges
so the line appears.

**Upstream status.** Not upstream.
