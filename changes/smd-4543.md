## Record

The session hook reads the outcome's soft wraps (SMD-4543)

**What changed** (`recipes/session-capture-hook/lib/secrets.mjs`, `lib/episode.mjs`; 1.11.6).
- **A soft-wrapped view.** `softWrapped` reads a lone line break as spaces, one for each of its characters, so every offset is the text's own. A blank line is not a wrap and is kept.
- **`scanForSecrets(text, { softWrap: true })`** reads the named patterns once more over that view and returns the union with the text's own findings, a finding both see once. The 64-hex rule is left out of the view's pass: its `sha256sum` exemption wants its digest at the start of a line, which a joined line no longer is. The entropy scan reads runs no line break is part of, so it is read once.
- **`redactSecrets(text, { softWrap: true })`** blanks what either reading finds, where the text has it, its lines kept. A span crossing only a soft wrap is a value cut by the wrap, blanked, not a key block; key material is still judged on the text's own lines.
- **The episode path:**
  - the outcome is blanked soft-wrapped;
  - the gate scans the outcome source soft-wrapped;
  - the model's excerpt scans its messages soft-wrapped.

  The prompts and the title are blanked on one line already. The rendered text's own scan reads as written, since the summary lists one prompt per line and joining those lines would join prompts.
- **1.11.6**, in `lib/hook.mjs` and `metadata.json`; the README's Testing list names the cases.

**Why.** SMD-3656's review pass 1 (secrets adversary) found that the password rule carries a quoted value to its closing quote only on its own line, and the outcome was blanked as written: a value a wrap cut was blanked to the wrap, and its second line sent. The ticket proposed blanking the outcome on one line, as the prompts are; the summary keeps the outcome's lines, though, so the outcome is read on one line where a wrap cuts it and blanked where the text has it, its layout unchanged.

**Held.**
- **The suite** passes under Bun: 1,096 assertions, three new.
  - **Outcomes:** three wrapped quoted passwords (`\n`, a short first word, `\r\n`) are blanked whole and pass the gate under redact, and are refused under refuse. A value a blank line ends keeps the next paragraph. A `sha256sum` line keeps its digest. A key block read soft-wrapped is still a block. A finding both readings see is one.
  - **The model's excerpt** is withheld for a wrapped quoted password, and sent for wrapped prose.
  - **End to end:** `prepare` and `--dry-run` on such an outcome leave none of the password in the payload or the output.
- **Nine mutants each fail the suite:**
  - the outcome blanked as written;
  - the excerpt read as written;
  - the gate reading the outcome as written;
  - the view's pass reading the 64-hex rule;
  - a blank line read as a wrap;
  - a CRLF not read as one wrap;
  - key material across a wrap no longer a block;
  - no dedupe of the two readings;
  - `redactSecrets` ignoring `softWrap`.
- **A differential against main** (70e0a608), through the episode path, over 1,036,800 structured outcomes and 60,000 random ones: no finding main makes under refuse is lost, no fragment main does not send is sent, no episode main's gate passes under redact is refused, and no excerpt main withholds is sent. What the branch blanks that main sent is, every time, a quoted value with a lone line break inside it.
- **Time:** 20,000 findings in one soft-wrapped outcome scan in 17 ms; a 105,000-character outcome of wrapped values redacts in 41 ms.
- `tsc --checkJs --noUnusedLocals` and `scripts/check-consistency.ts` pass.

**Not taken.**
- **The brain's copy.** `db/sensitivity.ts` reads a stored thought as written. A wrapped value that reached the brain before this release is read as before.
- **A value across a blank line**, or across a list of lines a quote never closes, is read as before: a blank line ends a paragraph, not a wrap.
- **The rendered text's scan** reads as written, so a wrapped value that reaches the text from elsewhere than the outcome is read as before. The prompts and the title are on one line already.
