## Changelog

The consistency checker holds deploy/README.md's path table to the proxy's route tables (check 28b). A path a router routes with no row fails, as does a row answering a path no router routes with anything but a 404. A row that doesn't name its router's backend (or 404 for a router to noop@internal) fails too, and so does an overlay's row that doesn't name its overlay file (SMD-2296).

## FORK

deploy/README.md's path table is held to the proxy's route tables (SMD-2296)

**What changed.**
- **Check 28b**, beside check 28 in `scripts/check-fork-consistency.ts`. It reads the README's `| Path | Answered by |` table and the four tables check 28 holds byte for byte (`ROUTE_FILES`: compose.yaml's, compose.api-public.yaml's, compose.hooks-public.yaml's and compose.grafana-public.yaml's):
  - **paths.** Every path a router's rule names (a `Path` or `PathPrefix` literal, the prefix's trailing slash dropped) is named in backticks in a row's first cell. `OPTIONS /health` names /health. Every path a row names there is a router's, or the row answers with a 404: /canary, /working and the rest of /.well-known are the proxy's own.
  - **backend.** The row naming a router's first path names, in backticks, the service compose runs behind it: its service URL's first label (`mcp`, `auth`, `app`, `api`, `lgtm`). For a router to noop@internal, the row says 404. An overlay's router's row names the overlay's file as well.
  - Seven self-probes, each a drift on the README as it stands (or a router added to compose.yaml's table), each expecting the problem its rule raises: a routed row dropped, another backend named, a row for `/canary/mcp` answered by `mcp`, the hooks overlay's file unnamed, `/register`'s row not saying 404, the header renamed, an unrouted `/probe/` router.

**Why.** SMD-2296's Work 4 asked that "the public-route table in `deploy/README.md` matches the proxy labels". Check 28 makes a route change a deliberate edit to the checker, but nothing made it an edit to the README. /hooks (SMD-2310), /grafana (SMD-1849) and /dashboard (SMD-2280) were each added to the table by hand. The table agrees with the routes today. This makes sure it still does after the next route.

- the full-stack job, `smoke.sh` and the GUI run through the proxy;
- the landing check names the new directories.
