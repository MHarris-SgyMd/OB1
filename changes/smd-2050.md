## Changelog

A typed-decision tier for the Jev spikes: `jev/serve.ts` serves Verdict v1.4 (a 151M calibrated decision model) on onnxruntime under Bun behind the `ob1-jev/1` contract, `server-portable/jev.ts` calls it through the egress gate (`OB1_JEV_BASE_URL`, `OB1_JEV_MODEL`, `OB1_JEV_LOCAL`), preflight checks it when configured, and `--profile jev` runs it beside the stack (SMD-2050).

## FORK

A typed-decision tier the Jev spikes share — one serving process, one client, one contract; the seven spikes stop each carrying a runtime (SMD-2050)

**What changed.** Four pieces, none on the server's request path:

- `server-portable/jev-contract.ts` — the wire contract, `ob1-jev/1`, with no
  imports: `GET /health`, `GET /info` (the model's name, source, revision,
  weights and calibrator sha256, the limits), `POST /decide` (up to 64
  `binary` or `choice` decisions → per-option probabilities with the tier's own
  `__insufficient_evidence__` option, `abstained`, binary `p_true`, the raw
  logits and the temperature). `jevRequestProblem` is the one validation rule
  both sides read.
- `jev/` — the serving process: `serve.ts` (routes, one request at a time,
  loopback by default), `verdict.ts` (Verdict v1.4 = `heman10x/rlcd-modernbert-151m`
  at a pinned revision, its reference engine's prompt, per-K temperature and
  `[SEP]`-keeping truncation ported and held to its strings),
  `fetch-model.ts` (fetch the pinned bytes to `.part`, rename only after the
  sha256 matches, verify every file on every start), `Dockerfile` (Debian slim:
  onnxruntime-node has no musl build; no weights in the image). A new
  type-checked directory (check 18) and a `FRAGMENT_DIRS` entry (check-landing).
- `server-portable/jev.ts` — the client: `resolveJevConfig` (null when
  `OB1_JEV_BASE_URL` is unset), `jevDecide` (the ticket's `(question, span,
  context)`, with the span written into the proposition by the caller),
  `jevChoose`, `jevDecideMany` (splits into 64s, validates every batch before
  sending any), `jevInfo`. Every decision is gated by `mayLeaveBox` against an
  endpoint `OB1_JEV_LOCAL` declares (`LocalKnob` gains it; the subject kind
  `decision`); when the caller gives no content, the decisions' own text is the
  `marker` unit. Failures are `ProviderError`s of the usual four kinds; an
  answer outside the contract, from another model than `OB1_JEV_MODEL`, or
  whose probabilities are not a distribution is a `body` error.
- Preflight, compose, docs — `jev tier` dials `/info` on every run when the
  knob is set (a wrong or unreachable URL fails the start, not a spike's first
  call), `jev egress` reuses the endpoint rows' rule, `--deep` adds `jev
  decision` through the client and its gate. `deploy/compose.yaml`: service
  `jev` under `--profile jev`, volume `jev-models`, no port (the host-ports
  file publishes it on loopback, `PUBLISHES` lists it), `restart:
  on-failure:3`; the server forwards the three knobs with no fallback — a
  default would fail every stack without the profile. `.env.example`,
  `deploy/README.md` "The typed-decision tier", `jev/README.md`.

**Why.** Seven spikes (SMD-1874, 1897, 1937, 2016, 2017, 2018, 2049) each
assumed a Jev-class model already loaded; the loading was work-item 1 of a
No-priority eval spike. The models do not fit the runtime the fork has: a
non-generative classifier returning a calibrated probability is not the
chat/completions shape Ollama serves, and Ollama exposes no option logits.

**What the ticket named and what runs.** openJev-verdict-2.0 is not servable:
its Hugging Face repository answers 401, and GitHub's LFS batch API answers
404 "Object does not exist" for its weights' pointer (oid `2201b07c…`, 598,509,338
bytes) in the repository and all 41 forks (checked 2026-09-23). Verdict v1.4 is the same author's
public checkpoint, the JevBench one — no separate confidence head, so
abstention is the explicit insufficient-evidence option. SemIf is Python-only
and goes behind the same contract as a follow-up (SMD-2052).

**Held.** `jev/test-jev.ts`, 75 assertions with no model ([1] the contract
rule, [2]–[4] the Verdict port against the reference's strings, [5] the engine
over fakes, [5b] the handler's statuses and serial queue, [6] the verified
fetch against a stub hub, [7]–[8] the client against a stub tier that counts
requests), 83 with `JEV_TEST_MODEL_DIR` ([9] the demo presets; [10] the
conformance run, `jev/conformance.ts`: the author's per-row receipt for this
bundle, 1,000 rows fetched pinned, reproduced exactly — every predicted option,
confidence within 6.4e-6, accuracy 95.0%, abstention 97.5% / 89.45%, ECE
0.0335, Brier 0.0785, all the report's; the served prompt and calibrator held
at their measured 93.1% and ECE 0.212 on the same rows). Eleven mutants, each
killed by the assertion it names: the gate dropped, no marker content, a batch
sent before the next is validated, no temperature, no per-K temperature,
truncation dropping `[SEP]`, no serial queue, any model accepted, a wrong hash
kept, the noul label's "not" dropped, a tokenizer losing `[CLS]` (982 of
1,000 rows agree; every hash passes). CI runs install, tsc and the suite in the
portable-server job; [9]–[10] skip there (no weights in CI).

**Measured after** (Apple M5 Pro; `jev/README.md` has the table). Host: load
0.8 s, 1,029 MB resident after load, one decision p50 18 / 30 / 62 / 146 ms at
60 / 126 / 258 / 512 tokens. Container (podman VM): first start fetched the
606 MB in 20 s, restart serves in ~1.2 s, 926–973 MB, the same probability as
the host, ~48 ms a short decision. A byte flipped in the volume's weights was
named, re-fetched and verified at the next start. Preflight's rows read as
designed against a live tier in six configurations (declared, undeclared,
wrong model, refused port, unresolved `jev`, unset).

**Provenance (SMD-1731).** Every answer names the model, source revision,
weights sha256 and calibrator sha256; a caller that stores a probability stores
those beside it. Nothing here holds lineage for a derived row — that table is
SMD-1731's.

**The served prompt costs on the receipt's set.** The v1.4 engine's `It is`
labels cost ~2 points of accuracy and 5 of abstention precision against the
evaluator's raw labels, and the bundle's open-domain calibrator leaves answers
unchanged but ECE 0.212 against 0.034; abstention last is free
(`jev/README.md`, "Conformance"). Kept as the engine ships it — its README
claims the framing gains 2–7 points on open-domain JevBench — and every result
carries the logits for a spike to refit.

**Not taken.** A Python sidecar for Verdict (onnxruntime-node under Bun runs
it, ids identical to transformers.js); transformers.js (the tokenizer alone is
360 KB, no dependencies); a padded batch (no faster than singles on this CPU);
a compose fallback for `OB1_JEV_BASE_URL`; the co-load measurement beside the
embedder and metadata model and the SMD-1937 consumer run — the second PR, by
the plan's cut.

**Follow-ups.** SMD-2052 — SemIf behind `ob1-jev/1` (a host adapter; Python, MLX).
