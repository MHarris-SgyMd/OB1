## FORK

A canary brought level in place, its own rows kept (SMD-3154)

**What changed.**
- `deploy/canary.sh`: `up --no-refresh`. Every refusal and step 2 run as `up` runs them (the env file's own port, address, tier, profiles and keys; the canary's database password). Step 3's refresh through `tier.sh` gives way to:
  - the canary's servers stopped, as before, and a running `sleep` worker too, which writes as it runs;
  - `migrate` built from this checkout and run once (`run --rm`, not `up`, which stays attached) on the canary's own database.

  Step 4 recreates the servers, proxy and forwarder; once the server answers, a worker that was running comes back on the new build, from `compose.yaml`'s definition; then the smoke and `--connect` as `up` does. A failed migration exits 1 and says what it left stopped. With no `<canary>_pgdata` volume it is refused before anything changes, beside `up`'s other refusals. The option goes with `up` alone.
- CI's canary step: a key only the canary holds, in its `ob1_config`, which a refresh's restore replaces, survives `up --no-refresh`; no tier half runs; the canary answers; a stand-in carrying compose's labels for its `sleep` service is stopped and replaced by compose's worker. After `down --volumes`, the option is refused (exit 2) and makes no volume.
- `deploy/README.md`'s "A canary beside the stack" names it.

**Why.** The dogfood canary holds rows stable does not, SMD-3006's ingested fork records and SMD-3115's decide-mode proposals, so a refresh would erase them, and since 2026-10-13 every canary upgrade has been a hand-made script in path mode. SMD-2874's dogfood move needs `up --port 8011 --connect`, which refreshed; the maintainer chose (2026-10-20) this option over another hand-made script.

**Held.**
- shellcheck and `bash -n` on `canary.sh`; actionlint on the workflow; the checker.
- The PR 2 harness (41) and the connector-key harness (5), run against this `canary.sh`: nothing before the new path moved. `down --no-refresh` exits 2.
- The CI canary step first runs the new path here, against a real stable and canary.
