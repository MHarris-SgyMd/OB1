## FORK

`recipes/repo-learning-coach` retires (SMD-2923)

**What changed.**
- **Deleted:** `recipes/repo-learning-coach/`.
- **Grants and schemas:** the `recipes` grant group loses the ten `repo_learning_*` tables (`db/config.mjs`, the `db/README.md` table), and `CONTRIB_SCHEMA_FILES` loses its schema file. The test-schema counts are in SMD-2920's record.
- **Its suites:** `extensions/test-writes.ts` drops its driven section and its `DRIVEN` entry.
- **The shim keeps `ignoreDuplicates`**, against the ticket's Work item 2. The ticket called this recipe its one caller, which holds only for the files already on the shim. Three scripts awaiting their port send `Prefer: resolution=ignore-duplicates`, and the disposition doc maps that header to `upsert(…, { ignoreDuplicates })`: atomizer's `entity-resolver.mjs` (SMD-2140), authorship-edges' `author-edges.mjs` (SMD-2141) and wiki-synthesis' `backfill-gmail-wikis.mjs` (SMD-2143). The path goes with the shim (SMD-3216). Only its comments, which named this recipe as current, change. Review pass 1 found it.
- **The checker:** the semicolon-less import reading that SMD-1799's second review pass added for this recipe stays. No file on the shim needs it any more, but it serves only the rule that reads shim importers, which retires with the shim (SMD-3216). Its comments no longer name the recipe as current.
- **Records:** `docs/vendored-disposition.md`'s row and rollup, and the root README's row.

**Why** (decided 2026-10-14):
- **It was unused:** stable had none of its ten tables, and no thought with its `lesson_slug` or `project_slug` keys.
- **Keeping it means a rewrite:** as a client of `/api`, or as a plugin with GUI pages. Either way, an app for a person to study with gets rebuilt.
- **What the maintainer saw in it was the brain learning a codebase.** That's SMD-3011, applied to Open Brain first in SMD-3006 and measured by a codebase Q&A eval: this recipe's quiz, aimed at the brain.

This also removes 1 of the 26 files that import `compat/supabase-sql` (SMD-3216).
