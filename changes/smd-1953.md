## Changelog

A wrong `OB1_TIER` (a case variant like `Stable`, or an unknown value like `prod`) no longer silently drops every `query_log` row — it is validated at boot (`initEnv` throws, and preflight's `tier` check fails so the container entrypoint refuses to serve) against one tier list `db/config.mjs` owns; and `parseFilter`'s size cap now counts UTF-8 bytes, not UTF-16 code units (SMD-1953).

## FORK

A wrong `OB1_TIER` is caught at boot instead of silently emptying the query log (SMD-1953)

`OB1_TIER` set to a value migration 045's `query_log.tier` CHECK rejects — a case
variant (`Stable`), or an unknown tier (`prod`) — made every `logSearch` /
`logActions` INSERT fail that CHECK. Because the log write is deliberately
best-effort (a log failure must never fail a search), the exception was swallowed
and **every query_log row was silently dropped**, with no error anywhere — which
would empty SMD-1806's canary replay (the canary replays stable's log) and defeat
the whole reason the `tier` column exists. Nothing stopped it: the `tier` preflight
check only warned.

The fix validates `OB1_TIER` at the boundary rather than leaning on the DB CHECK and
a swallowed exception. `db/config.mjs` now owns the one tier list — `PIPELINE_TIERS`
plus a `tierProblem(value)` validator (fail-fast and exact: unset is fine, anything
not exactly `stable`/`canary`/`working` is a problem, never silently lowercased) —
that migration 045's CHECK and `db/ingest-records.ts`'s `TIERS` (now re-exported from
it) mirror. The server's `initEnv` throws on a bad value where it freezes the
environment (the in-process guard, so a Workers deployment with no preflight
entrypoint refuses too), and preflight's `tier` check is now **fatal** on an invalid
value — so the container entrypoint `bun preflight.ts && exec bun index.ts` refuses
to serve, distinct from the tier *mismatch* it still only warns about.

A second, minor hardening in the same file: `parseFilter`'s `FILTER_MAX_BYTES` cap
measured `JSON.stringify(out).length` — UTF-16 code units, so multibyte content (CJK,
accents) passed at up to ~2× the byte bound the error names. It now measures real
UTF-8 bytes with `TextEncoder` (Workers-safe, where `Buffer` is not).

**Upstream status:** not sent — `OB1_TIER` and the pipeline tiers are the fork's own
release machinery (SMD-1806); upstream has no query log tier to validate.
