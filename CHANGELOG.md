# Changelog

All notable changes to the OB1 fork are recorded here, newest first, following
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/) and
[Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html).

This page is the short companion to [`FORK.md`](FORK.md), the fork's design record
— why each change was made, what was measured, what was declined. FORK.md remains
the record for changes 1–100, which predate the first release; this changelog
begins at the first cut. FORK.md's "Versioning" section has the scheme and how a
release is assembled from `changes/<ticket>.md` fragments.
